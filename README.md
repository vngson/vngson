### 🔐 Doculock — Proof of Existence & Document Authenticity Platform

[![Live Demo](https://img.shields.io/badge/Live-Doculock-6C63FF?style=flat-square&logo=vercel&logoColor=white)](https://doculock-kappa.vercel.app)
[![Source](https://img.shields.io/badge/Source-Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/vngson/Doculock)

A full-stack Web3 dApp for verifying document authenticity on the **SUI blockchain**. Privacy-first — files hashed client-side via SHA-256 in Web Workers, only cryptographic proofs stored on-chain.

| | Highlights |
|---|---|
| Smart Contracts | Custom **Move** contracts for proof registration & verification |
| Frontend | **Next.js 14** App Router + React Query + Tailwind CSS |
| Backend | **MongoDB Atlas** indexer with cursor-based pagination |
| Batch Processing | **PTB** for batch uploads in a single transaction |
| Features | Analytics dashboard, PDF/CSV/JSON export, QR codes, fraud detection |

`Next.js` `TypeScript` `Move` `SUI` `MongoDB` `React Query` `Tailwind CSS` `Web Workers` `SHA-256`

<!-- ═══════════════════ PHILOSOPHY ═══════════════════ -->

## ☄️ Engineering Philosophy

> I build software the way I'd build infrastructure — with the assumption that it will be used, extended, and depended on.
>
> Every system should have a clear architecture, every abstraction should earn its complexity, and every feature should solve a problem that actually exists. I value **readability over cleverness**, **simplicity over flexibility**, and **working software over perfect architecture**.
>
> The best code is the code someone else can understand, maintain, and build upon — six months from now, without you there to explain it.
