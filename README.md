## 🚀 Featured Projects

### Doculock — Proof of Existence & Document Authenticity Platform
[![Live Demo](https://img.shields.io/badge/Live-Doculock-6C63FF?style=flat-square&logo=vercel&logoColor=white)](https://doculock-kappa.vercel.app)
[![Source](https://img.shields.io/badge/Source-Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/vngson/Doculock)

A full-stack Web3 decentralized application for verifying document authenticity on the **SUI blockchain**. Built with a privacy-first architecture — files are hashed client-side using SHA-256 in Web Workers, and only cryptographic proofs are stored on-chain. No file content ever leaves the browser.

**Architecture highlights:**
- Custom **Move smart contracts** for on-chain proof registration and verification
- **Next.js 14** (App Router) frontend with React Query for server-state management
- **MongoDB Atlas** indexer with cursor-based pagination for scalable querying
- **Programmable Transaction Blocks (PTB)** for batch document uploads in a single transaction
- Analytics dashboard with PDF/CSV/JSON export, fraud detection simulation, and QR code generation

`Next.js` `TypeScript` `Move` `SUI` `MongoDB` `React Query` `Tailwind CSS` `Web Workers` `SHA-256`

### BlockHouse — Cross-Platform Business Application
[![Desktop](https://img.shields.io/badge/Desktop-WPF-512BD4?style=flat-square&logo=microsoft&logoColor=white)](https://github.com/vngson/BlockHouse_FE)
[![Web](https://img.shields.io/badge/Web-App-000000?style=flat-square&logo=nextdotjs&logoColor=white)](https://github.com/vngson/blockhouse-web)

A business management platform engineered for **both desktop and web** from the ground up. The dual-platform approach demonstrates architectural adaptability — sharing domain logic while leveraging platform-specific UI paradigms (WPF for desktop richness, React for web accessibility).

**Engineering aspects:**
- **WPF/.NET** desktop client with MVVM architecture and rich data binding
- **TypeScript** web application with modern component architecture
- Unified business logic layer adapted for each platform's strengths
- Complex data management with real-time state synchronization

`C#` `.NET` `WPF` `TypeScript` `MVVM` `SQL Server`

### Selina — Book E-Commerce Platform
[![Source](https://img.shields.io/badge/Source-Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/vngson/Selina)

A full-stack e-commerce platform built with a **microservices backend** architecture. Separate services handle authentication, book catalog management, and user profiles, communicating through well-defined API contracts.

**Architecture highlights:**
- Microservices decomposition: Auth, Bookshelves, and Profile services
- **MongoDB Cloud** for persistent storage with **Redis Cloud** for caching
- **Firebase Storage** for media assets
- Deployed on **Netlify** with environment-based configuration

`JavaScript` `Node.js` `MongoDB` `Redis` `Firebase` `Microservices` `Netlify`

<!-- Philosophy -->
## ☄️ Engineering Philosophy

> I build software the way I'd build infrastructure — with the assumption that it will be used, extended, and depended on.
>
> Every system should have a clear architecture, every abstraction should earn its complexity, and every feature should solve a problem that actually exists. I value **readability over cleverness**, **simplicity over flexibility**, and **working software over perfect architecture**.
>
> The best code is the code someone else can understand, maintain, and build upon — six months from now, without you there to explain it.
